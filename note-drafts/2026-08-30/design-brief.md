# デザイン担当:表紙・告知画像コンセプト(2026-08-30)

対象記事:「本業の空きコマだけで月2.5万円。未経験から「オンライン家庭教師・スキルシェア」を始めてみた話」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/2cc5f302-28e2-49ad-96d1-820718c60407

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「生徒ゼロからどう始めた?」という気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | 「月2.5万円の副収入」という成果を実績レポート風に |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×ゴールド(アカデミック感) | 「教える」という専門性・落ち着いた信頼感 |
| 06 | パステルラベンダーブルー×タイポ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | 登録→体験→継続 フロー図解 | 生徒獲得までの流れを視覚化 |
| 09 | 温かみグラデーション(グリーン×ゴールド) | 実体験・安心感のあるトーン |
| 10 | コーポレート×教育バッジ | 「教える」専門性・信頼感を象徴 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な保証表現(「必ず稼げる」「誰でも簡単に」等)は使わない
- 特定のスキルシェア系プラットフォーム名を断定的に挙げない
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
