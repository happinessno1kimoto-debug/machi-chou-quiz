# デザイン担当:表紙・告知画像コンセプト(2026-08-27)

対象記事:「在庫ゼロ・原価ゼロ。Notion/Canvaテンプレートを作って売ってみた話」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/f2f9cf2f-7b63-453e-8eca-525b7d7a5212

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「時間を売るのをやめた」という気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | デジタル商品販売という新ジャンルを実績レポート風に |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×シアン(テック感) | Notion/Canvaというデジタルツールらしい先進性 |
| 06 | パステルスカイブルー×タイポ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | テンプレカードのショーケース | Notion/Canvaのカードモックアップで「商品」を直接見せる |
| 09 | 温かみグラデーション(ゴールド系) | 実体験・「積み上がる収入」のイメージ |
| 10 | コーポレート×パッケージバッジ(紫系) | デジタル商品・パッケージ感を象徴 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な成功保証表現(「必ず売れる」等)は使わない
- Notion社・Canva社の公式テンプレートと誤解されないよう、あくまで自作テンプレートである前提のデザインにしている
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
