# デザイン担当:表紙・告知画像コンセプト(2026-08-23)

対象記事:「スキマ時間で月3万円。『AI議事録・要約代行』副業のはじめ方」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/7a6245b3-e3ec-483e-a538-30276f541e23

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 信頼感・落ち着き。煽らない誠実な印象 |
| 02 | エディトリアル×黒×赤差し色 | 雑誌の特集記事のような説得力 |
| 03 | ビジネスドキュメント風 | レポート感・データに基づく信頼性 |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×テック | AI活用感・先進性 |
| 06 | パステル×タイポグラフィ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | グラフ数字訴求(実データ棒グラフ) | 「1ヶ月目→2ヶ月目」の伸びを視覚化 |
| 09 | 温かみグラデーション | 実体験・感情に訴えるトーン |
| 10 | コーポレート×信頼バッジ | 安心感・審査済みのような信頼感 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な収益保証表現は使わず、あくまで実績ベースの数字(月3万円)のみを訴求
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
