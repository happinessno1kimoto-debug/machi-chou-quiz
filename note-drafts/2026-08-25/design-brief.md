# デザイン担当:表紙・告知画像コンセプト(2026-08-25)

対象記事:「クラウドソーシングの単価、これで2倍になりました。私が実践した『値上げ交渉』のやり方」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/eed15648-dbbb-44c9-9a92-884910bd1d01

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「交渉していないだけ」という気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | データに基づく信頼性、実践記録感 |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×交渉ログ風(紫アクセント) | 分析的・ログ記録のような先進性 |
| 06 | パステル×タイポグラフィ中心(コーラル系) | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | Before/After図解(¥1,500→¥3,000) | 「2倍」を視覚的にわかりやすく訴求 |
| 09 | 温かみグラデーション(青系) | 実体験・落ち着いた説得力 |
| 10 | コーポレート×信頼バッジ(握手アイコン) | 交渉成立・信頼感の象徴 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な成功保証表現(「必ず単価が上がる」等)は使わず、あくまで実体験ベースの数字(2倍)のみを訴求
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
