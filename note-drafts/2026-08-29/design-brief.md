# デザイン担当:表紙・告知画像コンセプト(2026-08-29)

対象記事:「副業のお金、口座を分けたら管理がラクになった話」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/2959d418-c54e-4eca-bbc5-5a9cefa2b940

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「お金がどこに消えてる?」という気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | 「手取りの見える化」という成果を実績レポート風に |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×ゴールド(金庫感) | お金・資産管理らしい重厚感 |
| 06 | パステルラベンダーブルー×タイポ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | 3口座振り分け図解 | 「入金→税金/生活費/貯め置き」の流れを視覚化 |
| 09 | 温かみグラデーション(グリーン×ゴールド) | 実体験・安心感のあるトーン |
| 10 | コーポレート×金庫バッジ(紺×ミント) | 資産管理・信頼感を象徴 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な保証表現(「必ず安心」等)や、個別の税務・金融アドバイスと誤解される断定表現は使わない
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
