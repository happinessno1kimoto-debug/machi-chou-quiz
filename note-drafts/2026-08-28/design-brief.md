# デザイン担当:表紙・告知画像コンセプト(2026-08-28)

対象記事:「提案文・見積書、ChatGPT/Claudeで時短作成してみた話」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/07241eb1-3ff2-45c4-963c-460b30d4da25

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「AIに任せた」という気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | 時間圧縮という実務的な成果を実績レポート風に |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×マゼンタ(AI感) | プロンプト・コマンド風の先進性 |
| 06 | パステルミント×タイポ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | 作業時間Before/After図解 | 「30分→数分」の時短を視覚的に訴求 |
| 09 | 温かみグラデーション(サーモン系) | 実体験・落ち着いた説得力 |
| 10 | コーポレート×ドキュメントバッジ(ティール系) | 書類・ビジネス文書らしい信頼感 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な成功保証表現(「必ず時短になる」等)は使わない
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
