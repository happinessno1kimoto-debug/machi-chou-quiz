# デザイン担当:表紙・告知画像コンセプト(2026-08-24)

対象記事:「副業の確定申告、実は『経費』で損してる人が多い話」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/e4c29f9e-3a47-4c1e-819a-befaf5f3cae8

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。書類・帳簿らしい誠実さ |
| 02 | エディトリアル×黒×赤差し色 | 「損してる人が多い」という警鐘トーン |
| 03 | 公文書グリッド風(白×紺) | 確定申告らしいフォーマルさ・正確性の印象 |
| 04 | 家計簿ノート風 | 親近感・「自分ごと」として読める雰囲気 |
| 05 | ダーク×会計アプリ風 | ツール活用・効率化のイメージ |
| 06 | パステル×タイポグラフィ中心 | 初心者にもやわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | レシートビジュアル型 | 「経費にできるかも」を視覚的に訴求 |
| 09 | 温かみグラデーション | 安心感・実体験に基づくトーン |
| 10 | コーポレート×信頼バッジ | チェックリスト感・審査済みのような信頼感 |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 税務に関する断定的・誇大な表現(「絶対に否認されない」等)は使わない
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
