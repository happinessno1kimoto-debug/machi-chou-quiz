# note有料記事 収益化プロジェクト

「副業・お金の稼ぎ方」ジャンルで、1日1本ペースで有料note記事の下書きとX告知文を作成するための作業フォルダです。

## 現状できること / できないこと

- ✅ 人気ジャンルのリサーチ、記事の執筆・校正、X告知文の下書き作成
- ✅ Gitでの下書き管理(このリポジトリのブランチ `claude/paid-note-monetization-8n02pz` にコミット)
- ❌ note.comへの実際の投稿(note API連携・ログイン情報が未設定のため)
- ❌ Xへの実際の投稿(X API連携が未設定のため)

note.com / Xの投稿を自動化する場合は、それぞれの連携情報(note投稿用の認証情報、X APIキー等)を用意してください。連携が整い次第、下書き作成の後工程として自動投稿ステップを追加します。それまでは、生成された下書きを人が確認のうえ手動で投稿する運用です。

## フォルダ構成

```
note-drafts/
  README.md          ← このファイル
  topics-log.md       ← 過去に扱ったテーマの記録(重複防止用)
  YYYY-MM-DD/
    article.md         ← note有料記事の下書き(タイトル・無料部分・有料部分・価格案)
    x-post.md           ← 告知用Xポスト文(複数パターン)
```

## ジャンル方針

**副業・お金の稼ぎ方**(2026年note市場リサーチに基づく方針)

- 「副業」のような一般論ではなく、「AI活用×副業」「スキマ時間×月◯万円」のように **具体的な数値目標・手法** を切り口にする
- 実体験ベース(やってみた・失敗談込み)で信頼性を出す
- 無料部分でしっかり価値を出し、有料部分で「具体的な手順・テンプレート・数値」を出す(いわゆる「立ち読みで満足させない」設計)
- 価格は当面300〜500円程度でレビューを積み上げる方針(高単価は実績が付いてから)

## 日次運用フロー(毎朝6:00 JSTを想定)

1. `topics-log.md` を確認し、直近のテーマと重複しないテーマを選定
2. 関連キーワードで簡単な市場リサーチ(人気の有料note傾向、検索トレンド)
3. 記事下書きを作成(構成: フック→共感→無料パート→有料パートの予告→有料パート→まとめ+CTA)
4. 誤字脱字・論理矛盾・薬機法/景表法上の誇大表現(「絶対稼げる」等)がないか校正
5. X告知文を2〜3パターン作成(スレッド形式・単発ポスト形式)
6. `topics-log.md` に本日のテーマを追記
7. コミット&プッシュ

## 注意事項(コンプライアンス)

- 「絶対」「必ず稼げる」等の断定的な収益保証表現は使わない(特定商取引法・景品表示法上のリスク)
- 実体験ベースの記述は誇張しすぎない
- 他者の有料コンテンツの文章・構成をそのまま模倣(盗用)しない。あくまで「売れる型」を参考にしたオリジナル記事を書く
