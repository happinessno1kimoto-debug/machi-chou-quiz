# デザイン担当:表紙・告知画像コンセプト(2026-08-26)

対象記事:「単発で終わらせない。Webライティングで継続案件を作る営業テンプレート」

note表紙(1280×670px相当)を10種類のトンマナで作成。X告知画像は note表紙とほぼ同じ比率(X推奨1200×675 / note標準1280×670)のため、同一デザインをそのまま流用可能です。

デザイン案(Artifactキャンバス、PNG書き出し可):
https://claude.ai/code/artifact/1eb3eb03-de3a-4cea-8dae-867a525ca591

## 10パターンの方向性

| # | トンマナ | 狙い |
|---|---|---|
| 01 | ミニマル×アースカラー | 落ち着いた信頼感。シリーズの基本トーン |
| 02 | エディトリアル×黒×赤差し色 | 「一言で変える」というシンプルな気づきを強く訴求 |
| 03 | ビジネスレポート風(白×紺) | 「3割が継続案件に」という実数を大きく見せる |
| 04 | 手書きノート風 | 親近感・個人の実体験感 |
| 05 | ダーク×琥珀アクセント | テンプレート感・ツールっぽい先進性 |
| 06 | パステルイエロー×タイポ中心 | やわらかく取り組みやすい印象 |
| 07 | 新聞コラム風 | 権威感・読み物としての信頼性 |
| 08 | 単発→継続の図解 | 「納品+一言→継続提案→3割が継続案件に」の流れを視覚化 |
| 09 | 温かみグラデーション(コーラル系) | 実体験・落ち着いた説得力 |
| 10 | コーポレート×リピートバッジ(緑系) | 「循環・継続」を象徴するアイコン |

## 使い方

1. Artifactを開き、気に入ったパターンをPNG書き出し
2. note投稿時の表紙画像として設定
3. 同じ画像をX告知ポスト(x-posts.md)に添付して使用可

## 注意

- 断定的な成功保証表現(「必ず継続案件になる」等)は使わず、あくまで実体験ベースの数字(3割)のみを訴求
- 最終的にどのパターンを使うかは人間が選定(オーナー判断)
